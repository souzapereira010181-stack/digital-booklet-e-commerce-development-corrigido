# Pagamentos

O painel agora aceita links reais de checkout do Mercado Pago e PagBank, adiciona `https://` quando o administrador cola o domínio sem o protocolo e impede links de outros domínios.

## Importante

O projeto **não cria uma cobrança automaticamente** apenas com o preço. Para isso seriam necessárias credenciais/API da conta do Mercado Pago ou PagBank.

Para vender imediatamente:

1. Crie o link de pagamento no Mercado Pago.
2. Crie o link de pagamento no PagBank.
3. No painel Admin > Apostilas, cole os links nos campos correspondentes.
4. Salve a apostila.
5. O botão da loja abrirá o checkout real em uma nova aba.

Não use links de exemplo como `https://mpago.la/1234567` ou `https://pag.ae/1234567`.
