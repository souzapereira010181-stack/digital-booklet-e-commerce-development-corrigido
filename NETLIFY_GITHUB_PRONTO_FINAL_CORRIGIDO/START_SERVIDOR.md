# Iniciar a loja local

Abra o PowerShell dentro desta pasta e execute:

```powershell
npm install
npm run dev
```

Depois abra `http://localhost:3000`.

Se a porta 3000 estiver ocupada, o Next.js mostrará outra porta no terminal, como `http://localhost:3001`.
